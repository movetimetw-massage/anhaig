# 安海居 GitHub Pages 網站（成交導向 v3）

此版本針對「更美化、不要有 AI 感」重新優化，方向如下：

- 版面從公告式資訊頁，調整為較有質感的品牌官網風格
- 減少機械式重複區塊，改成更有節奏的 editorial layout
- 保留原始資料的關鍵內容，同時提升閱讀性與手機體驗
- 明確區分：最新價格版本、需再次確認項目、延伸美學項目

## 主要頁面
- `index.html` 首頁
- `services.html` 服務項目與套餐
- `pricing.html` 價格、精油與車馬費
- `team.html` 服務團隊
- `booking.html` 預約流程與取消規則
- `faq.html` 安全提醒與常見問題

## GitHub Pages 部署方式
1. 建立 GitHub repository
2. 將本資料夾全部檔案上傳到 repository 根目錄
3. 進入 **Settings → Pages**
4. Source 選擇 **Deploy from a branch**
5. Branch 選擇 `main`（或 `master`）與 `/root`
6. 儲存後等待部署完成
